Mini Games

Click a thumbnail to play the game on its own page - right in your browser, no install or login needed. More games will be added here over time.

Available games

  • Tetris — the classic falling-block puzzle. Fill a row to clear it, and clearing several at once is worth the most.
  • Brick Breaker — bounce the ball with your paddle to break all 40 bricks. You start with 3 lives.
  • Memory Match — a card-matching game using PixelCraft Studio's original icons. Match all 8 pairs to finish.

Every game runs directly in your browser with no install or login required. Each game's own page has the full controls and scoring details.
