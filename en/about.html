About PixelCraft Studio

What PixelCraft Studio is, and the direction we're building it in.

What is PixelCraft Studio?

PixelCraft Studio is a free support site built for people making games. Whether you're an indie developer or making a game as a hobby, you can edit images right in your browser with no install required, grab ready-to-use pixel art assets, and find out what tools other developers actually use to build their games.

How we operate

We focus on making the small, recurring tasks of game development simpler. Image processing happens inside your browser rather than on a server, so it's fast and safe, and resources like pixel art assets or tool information are gathered in one place instead of scattered across the web. We add features deliberately, one at a time, keeping the interface simple and clutter-free.

Available now

  • Resize Image — quickly adjust a sprite or thumbnail's width and height in pixels or by percentage.
  • Pixel Image Picks — 43 original 8-bit pixel icons you can search, browse, and download with no license restrictions.
  • Guides — practical game development guides on pixel art sprite sizing, choosing a game engine, and free assets with licensing pitfalls.
  • Game-Making Tools — a quick summary of widely-used game development tools like Godot, Unity, Construct 3, Unreal Engine, GameMaker, and RPG Maker.
  • Image Request — post a request for a pixel icon or image you'd like to see, and browse requests from other visitors.

Coming soon

We plan to add image tools like cropping, file-size compression, and format conversion between JPG/PNG/WEBP, along with more pixel art assets and resources for game development. New additions will appear in the top navigation as soon as they're ready.
